LANCast Source

Une Source est un poste client LANCast, par exemple PC02, PC03 ou PC04.

Rôle

La Source prépare un flux local pour le Viewer PC01. Chaque Source doit avoir un nom unique.

Convention

  • Nom Source : PC02, PC03, etc.
  • Viewer cible : 10.10.10.10.
  • Nom de flux : PC02-ECRAN1.

À retenir

  • Ne pas utiliser deux fois le même nom.
  • Vérifier la connexion réseau avec le Viewer.
  • Tester une seule Source avant d'ajouter les autres.

Cette page est une description lisible pour le dépôt. La page Source complète doit venir de la livraison LANCast validée.
