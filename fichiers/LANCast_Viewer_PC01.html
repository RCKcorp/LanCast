LANCast Viewer - PC01

Page de repère / documentation

Le Viewer est le poste central. Il affiche les flux envoyés par les postes Source et héberge le serveur de signalisation LANCast.

Rôle du Viewer

ÉlémentDescription
Poste conseilléPC01
IP type10.10.10.10
Service associéSignalServer.ps1
Port par défaut8080

Contrôles rapides

  • La carte réseau dédiée doit être active.
  • La tâche planifiée LANCast SignalServer doit exister.
  • La page /health du serveur doit répondre.
  • Les Sources doivent pouvoir joindre l'IP du Viewer.

Important

Cette page sert de description claire dans le dépôt. Pour le déploiement terrain, utiliser la page Viewer complète issue de la livraison validée LANCast.
